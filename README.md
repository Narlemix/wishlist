# Вишлист

Список желаний со ссылками на магазины: https://narlemix.github.io/wishlist/

Сайт статический и живёт на GitHub Pages. Весь список хранится в `data.json`, страница просто показывает его.

## Как редактировать

1. Создай токен на https://github.com/settings/personal-access-tokens/new:
   - **Repository access** → Only select repositories → `wishlist`;
   - **Permissions** → Repository permissions → **Contents: Read and write**;
   - срок действия — какой удобно (по истечении просто создай новый).
2. Открой сайт, внизу нажми «Кабинет владельца» и вставь токен. Он хранится только в этом браузере.
3. Добавляй, меняй и отмечай подарки. Каждое изменение сохраняется коммитом в `data.json`, у остальных сайт обновится примерно через минуту.

## Быстрое добавление

После входа внизу сайта появляется кнопка «＋ В вишлист». Её нужно перетащить на панель закладок браузера. На странице товара в любом магазине нажми закладку: она прочитает название и цену прямо со страницы и откроет сайт с заполненной формой.

Для ссылок Wildberries сайт также пробует сам получить цену через открытый API магазина, когда ссылку вставляют в форму.

## Гости и брони

Гости регистрируются по имени и паролю и бронируют подарки кнопкой «Подарю я». Один товар может забронировать только один человек, у товара появляется плашка «Хочет подарить <имя>». Имена уникальны без учёта регистра.

Аккаунты и брони хранятся в Firebase (бесплатный тариф Spark):

- `firebase-config.js` — настройки веб-приложения Firebase (они публичные по задумке Firebase);
- `firestore.rules` — правила базы: брони может создавать только вошедший гость от своего имени, удалять — только свою, менять чужие нельзя.

Пока в `firebase-config.js` стоит `null`, гостевые функции скрыты, а сайт работает как раньше.

## Важность

У каждого желания один из пяти уровней, от самого важного к наименее: «Очень нужно», «Нужно», «Хочу», «Было бы приятно», «Когда-нибудь». В `data.json` это поле `priority` со значением от 1 до 5. Список сортируется по нему, подаренное уходит в конец.

## Проверка ссылок и цен

Раз в день запланированная задача Claude открывает ссылки и записывает результат в каждый товар:

- `check` — доступность: `ok` — товар доступен, `gone` — ссылка не работает или товара нет в наличии, `unknown` — проверить не удалось;
- `price` — текущая цена с маркетплейса, `priceAt` — когда её считали;
- `pricePrev` и `priceChangedAt` — прошлая цена и дата изменения. На сайте изменение за последние 30 дней видно как «↓ 300 ₽» или «↑ 300 ₽».
